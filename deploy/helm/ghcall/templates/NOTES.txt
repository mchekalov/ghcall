{{ if include "ghcall.usesGitLab" . -}}
Some filters target GitLab. ghcall reports those merge requests, but never
approves, merges or comments on them — and never sends them to the autofix
agent: that container can only fix a GitLab MR from inside its own failing
pipeline. Each run logs how many GitLab candidates it skipped.

{{ end -}}
{{ if .Values.agent.enabled -}}
The CI-autofix agent is ENABLED. Every PR reported with a failing CI state
gets one Job named ghcall-autofix-<repo>-<pr>:

  kubectl get jobs -n {{ default .Release.Namespace .Values.agent.kubernetes.namespace }} -l app.kubernetes.io/name=ghcall-autofix

That name is also the dedupe key: while the Job exists, a second ghcall run
for the same PR is skipped. The window is jobTTLSeconds
({{ .Values.agent.kubernetes.jobTTLSeconds }}s), so a PR that fails again
within it is not re-triggered until the finished Job is garbage-collected.
